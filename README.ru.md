# Matrix Client

*[Read in English](README.md)*

Клиент для [Matrix](https://matrix.org). Логика клиента — на **Rust**
поверх [`matrix-rust-sdk`](https://github.com/matrix-org/matrix-rust-sdk);
интерфейс — на **Flutter**, связь с Rust-ядром через
[`flutter_rust_bridge`](https://github.com/fzyzcjy/flutter_rust_bridge).

Статус: **ранняя альфа**, актуальное состояние и план — в
[`ROADMAP.ru.md`](ROADMAP.ru.md). Для повседневного использования пока
не готов.

## О проекте

Это личный эксперимент: с его помощью я выясняю, на что реально
способны современные ИИ-модели в разработке «от и до», под реальным
контролем, а не в виде игрушечной демки. Делается в основном для
собственного повседневного использования, а не как продукт для широкой
аудитории.

То, что это личный/экспериментальный проект, не значит, что безопасность
делается «спустя рукава» — реальная политика, по которой проверяется
этот код, описана в [`docs/SECURITY.md`](docs/SECURITY.md).

## Область охвата (scope)

v1 нацелен только на **десктоп: Windows и Linux**. Без Android/iOS/
macOS — телефонный клиент планируется отдельным проектом позже, а не
частью этого.

## Структура репозитория

- `crates/` — Rust-воркспейс:
  - `matrix-client` — сессия, синхронизация, комнаты, пространства,
    таймлайн; обёртка над `matrix-sdk`/`matrix-sdk-ui`. Не зависит от
    bridge-тулинга, тестируется обычным `cargo test`.
  - `matrix-core` — разбор Matrix-идентификаторов без зависимости от SDK.
  - `matrix-storage` — политика хранения медиа-кэша.
  - `feedback-dto` — формат отчёта обратной связи (ещё не доработан).
- `flutter/` — Flutter-приложение. `flutter/rust` — bridge-крейт
  `flutter_rust_bridge`, намеренно исключён из корневого Cargo-воркспейса
  (см. `docs/ARCHITECTURE.md`).
- `design/` — визуальный референс, по которому строится интерфейс.
- `docs/` — заметки об архитектуре и безопасности, синхронизированы с
  реальным состоянием кода.
- `reports/` — датированные отчёты по сессиям разработки.

## Сборка

Поддерживаемый способ получить рабочее окружение — Nix, см. `flake.nix`.

```sh
# Работа только с Rust (cargo check/test и т.п. на matrix-client)
nix develop

# Сборка/запуск Flutter-приложения под десктоп (тянет GTK/Flutter —
# заметно более тяжёлое окружение, вынесено отдельно специально,
# см. flake.nix)
nix develop .#flutter
cd flutter
flutter build linux   # или: flutter run -d linux
```

Windows: Rust-воркспейс проверяется в CI на Windows, но саму
Flutter-сборку под Windows ещё ни разу не пробовали — считайте её
непроверенной, пока кто-нибудь реально не прогонит `flutter build
windows`.
